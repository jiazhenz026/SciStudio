# Project or library?

The rule you already felt between levels 2 and 3, now in one line:

**What lives in a project stays in that project. What lives in your library
follows you.**

Both are right, for different things — a one-off step belongs to its
project; a tool you will want again belongs in the library.

This is also why "one block, one job" (the Block card) pays off: a block
that does one thing cleanly is a block worth promoting.
