# Branches

A branch holds a **workflow variant for one data context** — one batch, one
instrument, one cohort. You did this in level 3: two branches, two variants
of the same analysis, switchable in one click.

Use branches to keep every adapted variant recoverable and comparable.
Unlike in software work, **merging is often not the goal** — the branches
*are* the result: one analysis, systematically varied.
