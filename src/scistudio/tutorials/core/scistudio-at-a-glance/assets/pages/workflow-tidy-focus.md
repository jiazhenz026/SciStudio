# Tidy and focus

Two conveniences for a crowded canvas — and the first question about any
"auto-organise" button is *will it break my work*, so here is the answer.

- **Tidy** computes a clean left-to-right layout and writes **only where the
  nodes sit**. Blocks, wires, and settings are untouched.
- **Focus** dims everything outside the selected block's neighbourhood. It is
  pure view state — nothing is saved anywhere.

Neither touches the science. The worst either can do is put things somewhere
you would not have.
