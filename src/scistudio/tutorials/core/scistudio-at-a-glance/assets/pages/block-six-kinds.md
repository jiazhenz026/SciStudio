# The six kinds

Every block is one of six base kinds — the same six the product itself uses
to categorise them:

- **io** — moves data in and out of the workflow: Load and Save.
- **process** — ready-made processing blocks that ship with SciStudio.
- **code** — a Python function you write. Your custom blocks are these.
- **app** — wraps an external program as a block.
- **ai** — a step where an AI agent does the work, like in level 4.
- **subworkflow** — a whole workflow folded into a single block.

You have already used four of the six by hand.
