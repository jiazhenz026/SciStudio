# History

The History tab remembers **every run**: which workflow ran and which
version of it, what parameters each block used, how long it took, whether it
succeeded, which data went in and came out — and the **environment** it ran
in: Python version, platform, key packages.

The environment is not trivia. It is what Restore checks against later, when
you ask "why does this fail today?"

New runs append. Old runs are never overwritten.
