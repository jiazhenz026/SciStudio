# Versions

Before **every run**, SciStudio saves a version of your project
automatically — a commit prefixed `auto`, whose id is written onto that
run's record. That is what makes every run a place you can return to.

You can also commit by hand. The `auto` prefix keeps the two apart in the
history: **automatic commits are the trail every run leaves; manual commits
are the milestones you chose to name.**

If the automatic save fails, the run still happens — that run simply has no
version to return to, and is marked so.
