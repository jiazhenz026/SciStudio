# The Learning Center

The **Learning Center** is the in-app home for learning SciStudio: guided
tutorials that walk you through the real interface, plus a **Reading** tab that
serves this user guide inside the application.

It opens automatically the first time you run SciStudio. Reopen it any time
from the toolbar's **Learning Center** button.

## Tutorials

The Learning Center lists tutorials by **source**, one tab per source. The
**core** source ships with SciStudio:

| Tutorial | What it covers |
|---|---|
| **Welcome to SciStudio** | Your first tutorial: what a workflow is, what a block is, what a plot is, and what History is for. |
| **What is a type** | SciStudio's data types and formats, making your own type and loader, the personal tool library, and interactive data analysis. |
| **What can the AI do** | How SciStudio's AI agent works in a real project. |
| **Two modalities, one answer** | A multimodal analysis combining data from two instruments. |

Starting a tutorial creates its practice project for you. While it runs, a step
card tells you what to do next and highlights the control to use in the real
interface; scripted agent replays can appear in the AI Chat strip. Your
progress is recorded, so you can leave and pick up where you left off.

## Reading

The **Reading** tab is this user guide, served from the copy bundled with your
SciStudio installation. It always matches the version you are running. Pages
you meet in a tutorial open here too.
